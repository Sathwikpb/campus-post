CAMPUS POST · INDEPENDENT STUDENT PROJECT

Support

Help for Campus Post 0.3.5, an independent student project for webmail.tu-ilmenau.de.

Start reading email

  1. Install the extension. Open TU webmail and sign in on the university’s own page.
  2. Click Campus Post in the lower-right corner, or the browser toolbar icon.
  3. Read the disclosure and choose “I agree — enable email tools”. No inbox scan is needed: opening an email shows Everything about this email in the popup: main points, action requests, eligibility, dates, warnings and useful links. Click a scanned inbox message for the same view. Use the Everything about this email button to refresh the current webmail message. Translation, editable calendar details and the original message follow below.
  4. Scan inbox is optional; choose it only to collect links and dates from more messages. Newest 200 is the default; you can choose up to 5,000. Checking runs only while the assistant is open.

The panel is empty or cannot connect

Refresh the signed-in TU webmail tab after installation or updating. Open an email. In Setup & privacy, reconnect the webmail tab. If the university has changed its mail layout, do not keep retrying a failing scan. The extension currently targets Roundcube webmail on this one university host.

Live view and translation

Open a message in webmail to see its details without scanning. If the full embedded assistant cannot load, a local live-email view displays the essentials. Use Inbox & agenda to reach the full assistant. After an update, click Reload for Campus Post in your browser’s Extensions page, then refresh webmail.

German-only messages can translate automatically using supported on-device translation. Enable the language once if a download is required. Installed language packs are reused when opening another message. Local extraction and dates do not depend on an AI subscription. An included English section is used directly.

Browser models

Key sentences work without AI. Full local translation and optional browser summaries require a compatible Chrome version, supported language pair, sufficient storage/hardware and a model download. Prepare the language after choosing the source and target. If the browser API is unavailable, use the email’s Google Translate option, which clearly explains that Google receives the chosen text. Browser right-click translation is another option. Page translation cannot translate images, PDFs, attachments, editable fields or cross-origin frames.

Calendar and registration

Check all dates and times. “Tomorrow” is based on the original email’s date; missing dates or AM/PM cause warnings. A counselling availability window is not your booked slot. Registration links open the original site; Campus Post does not register for you. Add to Google Calendar opens a draft you must save. It does not provide automatic synchronization. Download calendar file works with calendars that import .ics files.

Privacy and removal

Closing × hides the popup. Reloading webmail preserves recent messages in temporary browser-session memory, so a clicked email can be read without restarting a scan. Close the mailbox tab or use the erase control to clear that cache. Settings can clear an agenda or revoke access and erase all extension local data. Close other assistant panels afterward. See the privacy policy.

Known limits

Rules can miss or misinterpret information. Always check the original before attending, paying or registering. Threaded inboxes may omit replies; scans have size limits. Recent messages are restored within the session cache limits. When an English version is included, an English digest uses that section. German-only messages still need a translation option; the app does not pretend to translate them with extraction rules. Other universities and mobile browsers are not supported. This is an early-access build: real authenticated TU access and installed-extension behavior still need a final release check.

Early-access support

This guide is the public support resource for the Campus Post independent student project. Source code, releases and bug reports are available on GitHub. Use fictional examples in public issues. If these steps do not solve an issue, disable the extension and use ordinary TU webmail. Never share passwords, session tokens, full email contents or private meeting links in public reports.
