# Privacy

See the complete [packaged policy](../extension/privacy.html). Campus Post runs in your browser, uses your existing signed-in TU session only after consent, and has no developer mailbox service or analytics. Optional external translation/calendar links send chosen information to their providers. Models are optional and managed by the browser.

The public source, tests and release packages do not contain the developer's private mailbox audit records. Tests use synthetic content. Do not submit live mailbox exports, activation URLs, session tokens, passwords or private meeting links to GitHub.
